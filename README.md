One line about crypto and trading life. The program validates the joke against the bounty gate (1–200 characters, one line, not only whitespace) and writes it to `/output/entry.txt`.

The joke:

> I day-trade for a living. My living is ramen, my day is one red candle, and my trade is telling my mom I'm not unemployed.

The setup promises a living; the turn redefines every word of it — the living is ramen, the day is one red candle, the trade is telling Mom you're not unemployed.

## Run it

```sh
node main.ts
```

It prints the character count and writes the joke to `/output/entry.txt`.
